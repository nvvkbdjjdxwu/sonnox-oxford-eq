## Overview

Sonnox Oxford EQ is a precision broadcast-quality equalizer offering five bands of high-quality filtering with LP and HP filters, trusted by major recording studios worldwide.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Sonnox Oxford EQ** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Five Bands** | Low shelf, two parametric bands, high shelf, and high-pass filter |
| **Type I/II** | Two filter types with different Q behavior for versatile EQ shaping |
| **Analog Emulation** | Optional analog saturation and filter curve character modes |
| **Oversampling** | Up to 4x oversampling for high-frequency accuracy at 44/48 kHz |
